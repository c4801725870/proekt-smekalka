## Mesarovich's Hierarchy Theory

- Systems organized in hierarchical levels
- Each level has own objectives and constraints
- Coordination between levels via interfaces
- Vertical ordering: lower levels serve higher

## Klir's Systems Methodology

- Abstract vs concrete systems
- State space representation
- System behavior = trajectory in state space
- Modeling: real system → abstract model → analysis → interpretation

## Organizational System Model (Новиков)

OS = {Composition, Structure, Strategies, Preferences, Information, Operating Order}

| Component | Content |
|-----------|---------|
| Composition | Participants |
| Structure | Information, control, technology links |
| Strategies | Admissible actions (constraints, norms) |
| Preferences | Objective functions |
| Information | Knowledge at decision time |
| Operating Order | Sequence of info receipt and strategy selection |
