| AHP | Multi-criteria decision ranking | Complex decisions |

## AHP Process

```
1. Define problem and goal
2. Build hierarchy (Goal → Criteria → Alternatives)
3. Pairwise comparisons at each level
4. Calculate priority vectors
5. Check consistency (CR < 0.1)
6. Synthesize priorities for alternatives
```

## Pairwise Comparison Scale

| Intensity | Meaning |
|-----------|---------|
| 1 | Equal importance |
| 3 | Moderate importance |
| 5 | Strong importance |
| 7 | Very strong importance |
| 9 | Extreme importance |
| 2,4,6,8 | Intermediate values |

## Consistency Check

- Consistency Index (CI) = (λmax - n) / (n - 1)
- Consistency Ratio (CR) = CI / RI
- Acceptable if CR < 0.1

## Decision Matrix

| Problem | AHP Step | Why |
|---------|----------|-----|
| Complex decision | Build hierarchy | Structure problem |
| Multiple criteria | Pairwise comparison | Systematic weighting |
| Inconsistent judgments | Check CR | Validate reliability |
| Final choice | Synthesize priorities | Rank alternatives |
