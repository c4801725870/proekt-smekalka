## 8 Laws of Technical System Evolution

1. **Completeness** — TS needs: engine + transmission + working organ + control organ
2. **Energy conductivity** — Energy must flow through all parts
3. **Rhythm coordination** — Synchronize (or deliberately desynchronize) actions
4. **Increase of ideality** — More function, fewer resources
5. **Uneven development** — Subsystems evolve at different rates → contradictions
6. **Transition to supersystem** — Merge with other systems
7. **Transition to micro-level** — Move from macro to micro structures
8. **Increase of controllability** — More flexible, adaptive structures

## Contradiction Resolution

### Physical Contradictions — 4 Separation Methods

| Method | When to Use | Example |
|--------|-------------|---------|
| Separation in time | Param needed high/low at different times | Scaffold: solid during use, gone after |
| Separation in space | Param needed high/low in different places | Tank armor: thick front, thin sides |
| Separation upon condition | Param needed high/low under different conditions | Swim fins: flexible for swimming, rigid for walking |
| Separation between parts/whole | Whole has one value, parts have another | Bicycle chain: rigid links, flexible chain |

### Technical Contradictions — Resolution Process

1. Identify technical contradiction (improving X worsens Y)
2. Find improving parameter
3. Find worsening parameter
4. Look up in contradiction matrix → inventive principles
5. Apply principle to resolve contradiction

## Веполь (Substance-Field) Analysis

### Basic Formula
```
S1 ← F → S2
```
- S1 = object substance (what is acted upon)
- S2 = tool substance (what acts)
- F = field connecting them

### 5 Classes of Standards

| Class | Standards | Purpose |
|-------|-----------|---------|
| 1. Build/Destroy | 1.1-1.2 | Complete incomplete веполь; destroy harmful веполь |
| 2. Strengthen | 2.1-2.6 | Replace uncontrolled→controlled field; increase dynamism |
| 3. Transition | 3.1-3.2 | Create bisystems/polysystems; transition to micro-level |
| 4. Detection/Measurement | 4.1-4.3 | Add detectable substance; use resonance; measure derivative |
| 5. Without Introducing | 5.1-5.2 | Use voids, fields, external/temporary additions |

## Ideal Final Result (IFR)

**Formula**: The system doesn't exist, but the function is performed.

**Steps to IFR**:
1. Define the main useful function
2. Imagine the ideal result (function without system)
3. Identify what prevents achieving it
4. Find resources to overcome obstacles
5. Use existing resources (don't add new substances)

## Morphological Analysis

1. Define parameters (independent features)
2. List variants for each parameter
3. Generate all combinations
4. Evaluate and select best
